# Control Flow Exercises

## Objective
Implement programs using loops and conditional statements.

## Tasks
1. Check whether a number is prime.
2. Generate the Fibonacci sequence up to a specified number of terms.

## Concepts Used
- if-else statements
- for loops
- Scanner class
- Variables and operators

## Technologies
- Java
- Eclipse IDE

## Sample Output

Prime Number Check:
13 is a Prime Number.

Fibonacci Series:
0 1 1 2 3 5 8 13
